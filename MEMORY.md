# Building Reference - Organisational Data

<!-- project: /home/panda/.openclaw/workspace -->

- Building codes: K6 (e.g., K6L3 = building K6 Level 3), K8 (e.g., K8L1 = building K8 Level 1).
- Each building can be split by module (ET, MA, BK) and module number (1-15), format: <building><level>-<module>-<number> (e.g., K6L3-ET-13, K8L1-MA-7).
- Robots: CMMR01 near K6L3-ET-13; CMR01 near K8L1-MA-7. These two robot names are easily confused.
- Locations: K6 = Singapore West; K5 = Singapore Central; K8 = Singapore North-East.
- Example references: K6L2-ET-14 exists (structurally valid).
